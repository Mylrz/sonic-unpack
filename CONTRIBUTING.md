# Contributing to SonicUnpack

Thank you for your interest in contributing to SonicUnpack! 🎉

## Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/<your-username>/music-converter-desktop.git
   cd music-converter-desktop
   ```

2. **Install dependencies**:
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build and test**:
   ```bash
   npm run build
   ```

## Contribution Guidelines

- **Decryption Algorithms**: Must remain 100% offline and local. No remote analytics or network upload.
- **UI & Aesthetics**: Keep minimal, low-saturation grayscale aesthetic, 10–14px rounded corners, and smooth 150–250ms transitions.
- **Code Style**: TypeScript strict mode, clean component composition, clean i18n support across all supported languages (`zh-CN`, `zh-TW`, `en-US`, `ja-JP`, `ko-KR`).
